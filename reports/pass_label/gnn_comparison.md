# PassFrameGNN vs XGBoost on `progression_beyond_pass_k` (360 test subset)

Generated by `scripts/train_pass_gnn.py` (EXP-032).  Unchanged match-level split; test read once, after the model and seed were chosen on validation.

Test subset: 3,736 passes with 360 data from 9 World Cup 2022 matches; positive rate 0.217.  Graphs: train 18,234 / val 4,545 / test 3,736.

## Reading

Player positions alone (graph-only, no pass destination) reach ROC AUC 0.595 [0.578, 0.606] against 0.530 [0.502, 0.551] for `end_x` alone; event features dominate (final-recipe XGBoost event+360 on the same 360 subset: 0.728 [0.709, 0.748]).  This is not a like-for-like contest between feature sets.  The paired differences below are reported for completeness; they reflect that the GNN has neither event attributes nor the pass destination, not a like-for-like contest.

> **Note (EXP-033).**  The rows labelled "EXP-027 recipe" use the superseded XGBoost recipe (`scale_pos_weight`, 500 trees).  The final pass models use the *Reference* recipe (early stopping, unweighted): event+360 0.728 [0.709, 0.748], event-only 0.719 [0.698, 0.739] on this subset (`pass_model_final.md`).
